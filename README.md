# Sistema de Loja

Projeto desenvolvido em Dart com conceitos de
Programação Orientada a Objetos (POO).

## Classes desenvolvidas

- Cliente
- Produto
- Roupa
- Calcado
- Acessorio

## Conceitos utilizados

- Classes e objetos
- Encapsulamento
- Herança
- Getters
- Métodos
- Regras de negócio

## Objetivo

Desenvolver um sistema simples de gerenciamento
de clientes e produtos de uma loja.
