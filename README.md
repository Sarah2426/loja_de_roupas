# Sistema de Loja

Projeto desenvolvido em Dart e Flutter com conceitos de
Programação Orientada a Objetos (POO).

Disciplina: Tecnologias para Desenvolvimento de Software II – 3º TI – Prof. Everaldo Júnior.

## Integrantes

- Julia Maria
- Sarah Regina

## Tema

Loja que vende roupas, calçados e acessórios. As classes foram migradas do Java (3º bimestre) para Dart.

## Objetivo

Desenvolver um sistema simples de gerenciamento
de clientes e produtos de uma loja.

## Classes desenvolvidas (`lib/models/`)

- Cliente
- Produto
- Roupa
- Calcado
- Acessorio
- Pedido
- ItemPedido

## Conceitos utilizados

- Classes e objetos
- Encapsulamento
- Herança
- Getters
- Métodos
- Regras de negócio

## Tela

O `main.dart` mostra 6 produtos em um `ListView.builder`, usando `Card` e `ListTile`. Cada item exibe nome, preço, estoque e detalhes do tipo de produto. A `AppBar` mostra o nome do sistema.

## Como rodar

```bash
flutter pub get
flutter run -d chrome
```
